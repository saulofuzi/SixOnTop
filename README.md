# WHITE — Minecraft PvP Clan

Site estático em HTML/CSS/JS, pronto para GitHub + Vercel.

## Antes de publicar

No `index.html`, procure por:

`https://discord.gg/SEUCONVITE`

e substitua pelo convite real do Discord da WHITE.

Também altere:
- nome dos jogadores
- ELO
- vitórias/derrotas
- número de membros
- número de servidores
- eventos
- textos da equipe

## Publicar no Vercel

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Entre em https://vercel.com/
4. Faça login com GitHub.
5. Clique em `Add New...` → `Project`.
6. Selecione o repositório.
7. Clique em `Deploy`.
8. O Vercel vai gerar uma URL gratuita.

Não precisa de Node.js ou banco de dados para esta primeira versão.
